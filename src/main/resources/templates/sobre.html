Sobre o site

Jogos Bacanas é um site simples feito para reunir informações sobre jogos de diferentes estilos e épocas.

A ideia é apresentar cada jogo de forma direta, com uma imagem da capa, uma descrição e informações básicas como desenvolvedora, ano de lançamento e plataformas.

Este é um projeto de estudo que utiliza HTML, CSS, Java, Spring Boot e banco de dados para apresentar jogos e permitir o cadastro de sugestões.

O que você encontra aqui?

  • Capas e descrições de jogos.
  • Informações básicas sobre cada título.
  • Uma lista de gêneros de jogos.
  • Um formulário para sugerir novos jogos.
